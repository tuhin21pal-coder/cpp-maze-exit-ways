# Maze Path Counter
A C++ program that calculates the total number of possible paths from the top-left corner to the bottom-right corner of a grid using recursion.

# Features
Accepts custom row and column dimensions.
<br>
Calculates all possible paths using recursion.
<br>
Allows movement only in two directions: right and down.
<br>
Handles single-row and single-column grids.
<br>
Validates user input to prevent invalid dimensions.
<br>
Displays the total number of possible paths.
